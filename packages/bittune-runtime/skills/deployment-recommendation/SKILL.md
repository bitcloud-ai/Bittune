# 部署推荐清单

新部署或选型请求先用受管环境探测取得本机硬件快照。以 GPU 型号、数量、总显存与当前空闲、CPU、RAM、驱动和运行时为依据，结合用户用途给出推荐；用户已指定的模型、目录和资源边界优先保留。

由当前接入的 API 模型生成一份可编辑清单：

| 项目 | 推荐值或用户指定值 | 简短解释与依据 |
| --- | --- | --- |
| 模型 ID *、权重目录 *、量化 * | 与模型对应；未知目录标待补充 | 位宽与预估显存关系 |
| 引擎 *、镜像仓库 *、固定摘要 * | 已知值引用来源；未知摘要标待补充 | 引擎支持与镜像身份 |
| 上下文 *、显存比例 *、最大序列数 | 根据硬件给出保守默认值 | 上下文为输入加输出上限；序列数与请求并发不同 |
| 输入/输出 Token、并发、请求数、候选数 | 测量时给出有界预算；仅部署可不填 | 预热与正式请求分开 |

`*` 表示执行前必填。专业词在清单旁简要解释。硬件显存统一用GiB（字节除以1024³），不要混用十进制GB。未检查的权重和镜像说“尚未检查”，不说不存在。区分推荐估计与本机实测，保留显存余量，不承诺未经验证的兼容性或性能。缺少本机路径、精确镜像摘要时使用准备技能取得真实值，不编造值来创建计划。

清单给出后说：“可以直接采用这份清单，也可以告诉我需要修改的项。”用户接受整份清单即可继续，不要求逐字段确认、不要求重输默认值。用户修改后仅更新相关项。接受清单不代替后续下载、计划固化或服务启停的原生动作确认。

完成条件：建议与硬件快照对应、必填缺口可见，用户能直接采用或修改。用户只问推荐时在清单处结束；需要执行时继续用原受管计划、部署、测量和报告工具。
