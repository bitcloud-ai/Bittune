# 验收受管服务或本机回环端点

用户要验收、扫并发、看正确性、看缓存、看卡怎么配时使用本 Skill。不要自己跑测量命令。

## 先说范围

默认短套餐是四件事：聊天短句、长文检索、批量生成、代码。先用这四句话复述，再问要不要改范围。用户没确认范围之前，不要开始验收。

完整套餐和极限测量必须先说明影响，并得到明确同意。默认不要跑极限测量。

## 服务

受管服务是 bound。本机回环端点是 declared，不能进实测栏。已落库的数字按 binding 和出处引用。验收才使用套件。

## 怎么说结果

可以说结果的，只有测完的那一档。其余状态说「这一档没有测完」，并转述原因。没测完不是模型失败。

正确性没带数据包就说做不了，不要报一个准确率。

缓存做不了就说引擎不支持，不要说成模型没缓存。

卡怎么配是单机估算，不能拿去改部署参数。
